4. 隐私与 manifest
不能沿用“未收集数据”。本地 privacy-labels.json 有11类草稿：
Name、Email Address、User ID、Purchase History、Other User Content、Precise Location、Coarse Location、Other Usage Data、Other Diagnostic Data、Other Data Types、Performance Data。
账号、购买、用量及可恢复回答与用户关联，Linked to User=true；源码未见广告追踪，Tracking=false；开发者侧用途为 App Functionality。
上传给 AI 的 Name、Precise/Coarse Location、Other User Content、Other Data Types 另保守列 Other Purposes。
DeepSeek 通用条款允许在去标识化等条件下训练/优化；本 API 账户的具体用途、留存、处理地区和有效退出安排仍待确认，不能宣称绝不训练或只有功能用途。
自由文本按 Other User Content 处理，不因用户可能自行填写而枚举所有健康、财务或敏感类型；结构化生日、时刻与排盘性别归 Other Data Types。
当前 ASC 仍是旧的 Data Not Collected。长隐私表单的 Safari 自动化曾挂住（历史原因）；最后一次CUA复核明确Mac锁屏，当前无法继续操作或保存，新11类答案未保存、未发布；本地 JSON 和随包 manifest 都不代表 ASC 已填写。
最终ASC构建处理完成状态也因最后Mac锁屏而未读取；不用等待解锁即可整理本地资料，但不能把未读取状态当成已完成。
PrivacyInfo.xcprivacy 与 ASC 标签是不同事项：最终归档和导出IPA已确认随包包含有效清单，11类数据与本地标签一致，UserDefaults required-reason为CA92.1；这不代表ASC答案已经保存或发布。
privacy-manifest-audit.json 中 needs_resource_repackaging=true 是重打包前的历史源审计快照；后续最终 candidate-verification 已确认该步骤完成，保留历史文件不改写。
