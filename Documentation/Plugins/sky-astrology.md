# astrology · 西方占星

插件版本 `1.0.0+astronomy.865d3da`。`WesternAstrologyPlugin` 实现 `OraclePlugin`；由 `SkyPlugins.all` 注册。

## 计算能力

支持公历 1900–2100 年，热带黄道、地心视位置、日期真春分点。十大天体为太阳、月亮、水星、金星、火星、木星、土星、天王星、海王星、冥王星。计算本命黄经、逆行标志、合 / 六合 / 刑 / 拱 / 冲相位，以及当前行运天体对本命点的主要相位。

有确认的出生时间和出生地经纬度时，计算上升点、天顶、等宫制十二宫头和落宫。**等宫制不等于 Placidus，MC 不强制位于第十宫宫头。** 纬度绝对值达到 66° 时当前版本不提供宫位。

## 缺失资料

- 出生日期或时区未确定：返回 unavailable。
- 出生时间不确定：按出生地时区从当天 00:00 至次日 00:00 输出星位区间端点，返回 partial；不生成相位判词、宫位或上升点。
- 缺出生坐标：保留地心星位和相位，返回 partial；不会借用当前 GPS 坐标冒充出生地。
- 当前版本不含小行星、恒星、合盘、推运及其他宫制。

## 内核与离线依赖

使用 MIT 的 Astronomy Engine C，系数直接编译进应用，**不是 Swiss Ephemeris，也不需要外置 `.se1` 或 JPL 数据文件**。上游固定提交 `865d3da7d8112bbc7911238052c6af4aaf877181`。C 原文件见 `Vendor/Astronomy/astronomy.c/.h`，许可证同目录。应用自己的 `BlindOracleSky.c/.h` 只包装地心星位、中央差分速度与地平线 / 黄道交点。

Swift 桥接头必须包含 `BlindOracleSky.h`；编译 `astronomy.c` 与 `BlindOracleSky.c`，头文件搜索路径包含 `Vendor/Astronomy`。所有计算通过 actor 串行，避免并发访问 C 内核缓存。

## 符号规则与验证

本命相位容许度 6°，行运容许度 3°。行运只检查水星至冥王星对本命太阳至土星，展示最接近的十组；不以相位数量生成事件成功率。evidence 的极性是传统符号约定，强度只表示几何接近度，不是可信概率。

本地 C/Swift 命令行回归已验证完整输入、未知时辰、缺坐标与重复运行；2024-03-20 03:06 UTC 的太阳黄经约 359.999747°，在春分点附近。插件 XCTest 继续覆盖资料缺失时不伪造宫位和紫微时辰。
