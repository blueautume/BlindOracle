# 八字 / 四柱 · `bazi`

版本：2.0.0。执行位置：设备本地。入口：`OraclePlugin.calculate(OracleInput) async throws -> OracleResult`。

输入：出生日期、有效出生时区和出生地坐标必需，出生时刻和排盘性别可未知。出生地坐标由内置省市区目录或用户已确认的定位资料提供。缺少有效坐标时不退回钟表时排盘，不使用当前所在地替代出生地。明确撤回或标为未知的资料不得被旧值补回。

统一内核：`TrueSolarBaziEngine` 串行计算，资料表只读八字预览与正式 `BaziPlugin` 使用同一入口。预览直接显示原始中文干支；它不是可编辑或持久化的八字输入。修改出生日期、时刻、时区、出生地或坐标后重新计算，过期异步结果不能覆盖新输入；姓名、排盘性别和当前所在地不改变四柱。

时间口径：出生 `Date` 表示真实瞬间。离线采用 NOAA Julian-century 均时差模型与出生经度求当地视太阳时（真太阳时），日柱、时柱以该时间计算，沿用 sect 2 零点换日规则。立春换年、十二节换月仍按真实出生瞬间对照固定 UTC+08:00 的历法交节表，不能把校正后的钟表数字再次当作原始出生瞬间。历史夏令时由出生时区与真实瞬间转换处理一次，不重复减夏令时。起运与节气间隔按真实瞬间计算。

输出：四柱、日主、十神、藏干、五行表层计数、纳音、旬空；出生时刻与排盘性别明确时输出起运与八步大运。结果保留出生钟表资料、真太阳时校正及排盘口径，供后续解读沿用。

未知时刻：检查出生民用日期全天在真实时间和真太阳时间上的范围，列出必要的年、月、日柱候选，不用保存的中午占位时刻虚构时柱、起运或大运。真太阳时可能跨民用日期边界，不能一律固定日柱。1900–2100 为出生日期范围，太阳时校正后的日期允许跨相邻年端点。

能力边界：地区目录坐标是地区代表点，不是精确出生地址；群岛与大范围地区的代表点不能保证临界时刻的精细定位。五行是未加权计数，不以缺项推定喜用神；未实现完整格局、合化、根气与喜用神判断。

依赖与来源：6tail/lunar-swift MIT，本地 Swift 历法源码；NOAA 公开太阳时计算公式，运行时不请求网络、地图或 AI。

历史记录按其保存版本保留。普通追问可解释历史结果；出生资料变化后重新排出的八字使用 2.0.0 真太阳时口径，不能把新旧口径混称同一盘。测试覆盖真太阳时换时辰/跨日、交节、历史夏令时、未知与撤回资料、预览/正式结果一致和当前所在地独立性。
