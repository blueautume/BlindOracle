# 梅花易数 · `meihua`

版本：2.0.0。执行位置：设备本地。入口：`OraclePlugin.calculate(OracleInput) async throws -> OracleResult`。

三数法：已确认numbers至少三个整数时，前两数定上下卦，第三数除6定动爻。优先进入此分支，完全不访问时间或地点；即使起卦日期/时区无效或地点缺失仍可定卦。明确撤回numbers后不得复用旧数字。

双数法：前两数定上下卦，两个原数加起卦地真太阳时辰序数定动爻。数字先取余后相加，避免整数溢出。

时间法：未使用确认数字时，以起卦地真太阳钟面00:00纪日，再映射农历，取农历年支序数、月、日及太阳时辰。23:00仅进入子时，不另推农历日。闰月沿用该月序。双数/时间模式必须有有效当前所在地坐标、真实起卦时刻与时区；不借出生地点、不默认经度。

输出：适用模式的原始钟表时间、真太阳钟面、经度/均时差校正与纪日规则，本卦/互卦/变卦、动爻、体用、五行关系及起数过程。三数模式不显示伪造的太阳时间。典籍内容从本地iching-texts.json取本卦卦辞、对应动爻爻辞及变卦卦辞，缺文返回partial而不补写。

能力边界：普通互卦取本卦2/3/4与3/4/5，乾坤不另改取；不含完整外应或应期。太阳纪日是本项目固定规则，不声称所有梅花流派统一采用；地区坐标代表点不能保证边界附近的唯一结果。

新结果与unavailable结果均标2.0.0。既有历史结果不重算或改写，新盘不得复用1.0.0结果。rows、evidence、limitations和来源随结果保存。无HTTP、云历法或模型调用。

验收用例：`Tests/NativeSolarTimeTests.swift`覆盖三数无日期/地点、双数只改动爻、均时差跨时辰及真太阳纪日跨农历年；由主任务统一执行，本文不提前声称通过。
