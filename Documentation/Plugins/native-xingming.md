# 姓名五格 · `xingming`

设备本地。用户分别给姓与名，各1–4字。主算法采用本地63,696字康熙部首笔画表（breezyreeds/kangxi-strokecount，MIT ©2017–2018 Kawai Lo），数据按Unicode码点十进制键保存。

不能使用字形String作字典键：Swift规范等价会合并朗/朗等兼容字，原表存在不同笔画。本表用码点键完整保留63,696条。

简体与传统姓名：ICU Simplified-Traditional只生成繁体候选，不代表用户已确认。输入字形与候选不同，状态partial，展示原字形笔画、候选字形笔画及差异；请用户核对传统写法。输入已确认繁体且转换不变、主表完整时可complete，仍注明录文未全量校勘。例陈13不同于陳16，张7不同于張11，不直接按简体字当作传统姓名。

输出：天格、人格、地格、外格、总格及三才。地格在单字名时加1；天格在单姓时加1；外格由姓的非人格部分与名的非人格部分组合，单姓/单名缺位各补1。不采用五=5/七=7等数意流派替换。

备选：仅在康熙主表缺失时用chinese-character-strokes 0.0.3（ISC）压缩的现代笔画数表；现代降级结果始终partial。未知姓/名、缺字或含无法确定笔画的组合字形不猜测。

限制：不含完整81数理歌诀，不据姓名推断品格、能力或必然命运。资料源、转换和边界说明随结果输出。
