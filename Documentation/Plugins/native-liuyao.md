# 六爻 / 周易筮法 · `liuyao`

版本：1.0.0。完全设备本地。入口：`OraclePlugin.calculate(OracleInput)`。

输入：起卦时间与时区、持久化seed。`castingStyle=nil`或`coins`为三枚铜钱；`yarrow`为大衍蓍草三变归奇等价概率抽样。`manualLines`若有值则优先，必须是初爻到上爻的6个6/7/8/9。未支持的castingStyle明确拒绝。

铜钱概率：老阴6=1/8、少阳7=3/8、少阴8=3/8、老阳9=1/8。大衍概率：6=1/16、7=5/16、8=7/16、9=3/16。大衍以49策起，第一变去5/9（3:1），后两变各去4/8（1:1），余策除4成爻。记录三变去数供审计，不伪造实际人工分堆。

输出：本/变卦、动爻、八宫、世应、纳甲、六亲、六神、月破日冲/旬空；本卦卦辞、全部动爻爻辞、变卦卦辞；乾坤六爻全变另列用九/用六。

取文：本地`iching-texts.json`含64卦辞、384爻辞、64彖传；固定来自kentang2017/ichingshifa（MIT样式许可保留），只取公版古文，保留异体字与标点，不引入现代AI解释。多爻变完整展示动爻，不额外假定某一爻为唯一主断，不混用其他变占取文流派。

限制：仍为基础京房纳甲盘加典籍取文；未自动选择用神，未实现伏神、进退神、完整生克制化和应期，状态partial。经典吉凶用词不直接转成事件概率或权重投票。无HTTP、云历法、在线查卦或模型调用。
