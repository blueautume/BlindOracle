# 称骨 · `chenggu`

版本：2.0.0。执行位置：设备本地。入口：`OraclePlugin.calculate(OracleInput) async throws -> OracleResult`。

输入：确认出生日期、出生时区、出生地有效坐标；出生时刻可未知。有效确认坐标或已选区县代表点可满足，不强制另填地点文字。使用出生地点而非当前/起卦地点；撤回或缺失坐标不默认东经120度。

已知时刻：`TrueSolarClock.birth(profile:)`以真实出生instant计算当地经度与均时差校正。用真太阳钟面00:00纪日后的农历年、月、日、时查1946《大雜字不求人》录文表。农历换年，不以立春换称骨年；闰月沿用本月；23:00进入子时但不另换农历日。太阳钟面是纪日坐标，不是移过的真实天文instant。

未知时刻：不能采用表单保存的代表午时。共享`birthHourCandidates(profile:)`投影完整出生民用日（含历史23/25小时日）的真太阳时辰/日期候选。逐个合法日期和时辰组合查年/月/日/时权重，再取总重最小/最大；不能任意拼接不同候选的分项极值。结果仅列确认出生日期/时区/经度、候选农历日期、分项候选及总重范围，不展示代表午时的单一真太阳时间或均时差，不选择某首原诗。

输出：已知时刻完整clock trace、纪日规则、四项骨重和历史原诗；未知时刻返回partial范围。固定刊本2两1缺文不补造。原诗不得用于寿命、疾病或亲属结局等现实判定。太阳纪日为本项目选择，不声称是所有称骨传本的唯一口径。

依赖：1946公版扫描、DHCPSV/zhishi-bazi MIT录文、LunarSwift和共享TrueSolarClock。坐标为代表点时显示边界限制。无HTTP、云历法或模型调用。

新结果及unavailable结果标2.0.0。既有1.0.0历史记录不重算、不改写，也不能作为2.0.0新计算结果复用。

验收用例：`Tests/NativeSolarTimeTests.swift`覆盖出生真太阳跨午夜/农历年、未知时刻跨两农历日期的合法范围、农历换年及闰月；既有查表golden fixture改到民用00:30保持原农历日期，另单独验证原00:00应跨日。由主任务统一执行，本文不提前声称通过。
