# 规划阶段优化对比 · 3.0.305 / Build 68

日期：2026-11-17。分支：`perf/planning-latency`。

## 结果与口径

重点优化“选择适用方法与所需资料”。五条相同问题、相同空人员档案的实测中，规划请求中位耗时从 **9.939 秒降至 2.250 秒，减少 77.36%**；平均从 **15.600 秒降至 2.206 秒，减少 85.86%**。

两边使用相同服务器、供应商和 `deepseek-v4-pro`，均由实际网关 `prepare_payload` 生成有效上游请求。计时从 HTTPX 客户端及连接开始到完整响应收齐，不包含 App 配额准备、表单展示与本地解码。这是请求级对照，不是“穷奇”上整段界面响应时间的承诺。每题每版测一次，供应商负载、缓存与网络会波动，不能据此承诺日常高分位耗时。

## 慢在哪里

此前手机曾记录19、40、51秒的已完成规划阶段。这些历史会话和本次五条合成题的上下文不同，未混入上表计算。历史真实网关样本中，约92%–94%的输出 token 用于推理；一条截断请求的4096个输出 token 中，4061个用于推理。输入缓存命中达到99.7%时仍会慢，因此主要排查方向是规划推理负担，不能仅归咎缓存未命中。

本次旧版五题平均输出1205 token，其中推理1018.6、可见 JSON 186.4；新版平均输出179.8 token。规划的任务是选择流程和方法，完整解读所需的重推理留在最终回答阶段。

| 每请求平均指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 输入 token | 7599.8 | 2397.2 |
| 输出 token | 1205 | 179.8 |
| 有效规划策略 | thinking enabled / low / 4096 | thinking disabled / 2048 |
| 全部消息 UTF-8 字节 | 32939.2 | 10283.8 |
| 加权输入缓存命中率 | 80.51% | 45.92% |

新版供应商未返回 reasoning_tokens 字段，未把缺席字段伪造为测量到的零。新版缓存更冷仍更快；关闭规划思考与精简提示同时实施，不能单独量化两项各自的贡献。

## 具体修改

- 仅新规划请求携带 `planning_version=routing-v2`，使用同模型的 non-thinking 模式。服务端旧规划策略与已提交阶段指纹、缓存重放保持兼容；解读、追问的 thinking/max 和预算策略保持原样。
- 规划提示聚焦执行意图、事项引用、方法选择、参与者及表单需求。目录去掉源码、许可证、输出说明等路由无关元数据，保留十种方法的能力、完整必需/可选字段和交互类型。
- 最近12条用户原话及既有延续摘要完整保留；普通助手答文摘录，24条可引用消息及其关联推演摘要仍可寻址。引用摘录保留原800字上限。
- 规划不接收模型自动填写的 profileUpdates。用户在统一表单填写资料、选择已有人员并确认；既有档案复用、本地明确资料更正与各方法准备状态校验继续保留。
- 用户明确指定的方法由本地保留必选标记；缺少出生资料或起局地点时进入表单并说明限制，不静默换方法、不伪造输入。紫微缺必要出生时刻仍不能排唯一盘。
- 仅对英文直/弯撇号进行可逆原文对齐，恢复真实证据片段；改词、漏否定、被引用指令和对象歧义继续拒绝执行。

## 准确性与回归

真实模型矩阵覆盖八字、紫微、六爻、梅花、奇门、小六壬、称骨、姓名五格、西方占星、塔罗：每种方法均包含明确指定和按能力描述触发；另覆盖缺资料、多方法、多人、否定引用、模糊问题、已有解读、追加方法、重抽和假设资料不保存。

事件型即时方法的“本人/事件”都可能描述同一个共同问题，测试在逐条说明后接受两种标签，但额外选到个人资料方法时恢复严格对象检查；他人、多人及生辰方法保持严格归属。普通解释中的“朋友”可标为他人，仍必须不启动计算。

首轮真实测试发现并修复了：必选标记遗漏、英文撇号导致原文证据拒绝、资料缺项被当成事项歧义、英文起局地点未被表单识别、独立新问题附空引用导致解析失败，以及明确重抽漏掉必选标记。本地新增解析回归同时覆盖咨询、否定、引用与肯定分句，避免扩大中文“看/推算/补充分析”识别后误发起计算。

最终签名模拟器回归：**781项单元测试、2项界面测试全部通过**；最终**32/32条真实模型矩阵通过**，该轮客户端请求耗时中位约**2.09秒**。测试及安装证据见本批 `Validation.json` 及 `build/planning-3.0.305-68/verification.json`。本轮验证的是路由正确、真实准备流程、既有本地插件及回归，不把有限题集通过等同于证明所有问题的最终文本质量相等。最终解读模型、推理强度、提示与盘面输入策略未降低。
